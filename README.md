# DarknessTool1.0
DarnessTool - Утилита для Windows 10/11

Портативная утилита восстановления Windows после вирусных атак. Работает и в обычной Windows, и в среде восстановления (WinRE / WinPE). Один .exe ~66 МБ, без установки и зависимостей.

Возможности

· Диспетчер задач — просмотр, завершение, «заморозка» процессов (NtSuspendProcess), убийство дерева процессов.
· Автозагрузка — Run / RunOnce / Winlogon / службы / планировщик задач, в т.ч. в оффлайн-системе.
· Снятие ограничений — ~45 политик: блокировка taskmgr, regedit, CMD, панели управления, USB, сети и т.д. Плюс восстановление ассоциаций .exe/.reg/.bat.
· Проверка диска — CHKDSK, SFC (оффлайн), DISM с живым выводом.
· Редактор реестра — работает, даже если regedit.exe удалён. Полноценное дерево, правка значений, работа с загруженными оффлайн-кустами.
· Работа в WinPE — автопоиск Windows, загрузка кустов SYSTEM, SOFTWARE, NTUSER.DAT каждого пользователя.
· Доп. инструменты — очистка IFEO (Image Hijack), DisallowRun, запуск cmd/regedit.

Технически

· C# / .NET 8 / WinForms, x64, права администратора.
· Собирается автоматически через GitHub Actions — можно обновлять прямо с телефона.
· Исходники: github.com/darkjoons3-hue/DarknessTool1.0

⚠️ Не антивирус — инструмент восстановления, чтобы система снова загрузилась, и потом уже можно было чистить её полноценным AV.
